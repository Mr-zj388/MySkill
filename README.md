# MySkill

我的个人开发 Skill 集合，用于沉淀日常 AI 辅助开发中的工作方法，让代码定位、模块划分、能力复用和结果验证有明确的执行流程。

每个 Skill 独立存放，按任务需要选用；具体执行规则以对应的技能文件为准。

## Skill 清单

| Skill | 用途 | 适用场景 | 入口 |
| --- | --- | --- | --- |
| `codebase-navigator` | 按模块维护中文代码导航，记录职责、关键入口与相关文档，沿用项目已有导航约定 | 建立代码地图、同步受变更影响的导航 | [技能说明](codebase-navigator/SKILL.md) |
| `modular-development` | 明确业务模块归属、依赖方向与复用方式，并用实际行为验证开发结果 | 从零搭建项目、已有项目新增功能、修改业务逻辑、提取重复能力 | [技能说明](modular-development/SKILL.md) |

## 使用方式

在目标项目中开展任务时，让 AI 助手读取所需 Skill 的入口文件，再结合项目自身的约定执行。读取时保留 Skill 的完整目录，便于继续访问引用文件。

未配置技能加载时，可以在对话中明确指定技能文件的实际路径。例如，将下面的占位内容替换后发送：

```text
请先读取 <MySkill 所在目录>/modular-development/SKILL.md，
再按其中的流程完成当前项目的开发任务：<具体需求>。
```

如使用支持 Skill 加载的工具，按该工具的要求配置技能目录，再使用其调用方式。每个 Skill 的入口文件统一为 `SKILL.md`。

### 维护代码导航

读取 `codebase-navigator/SKILL.md` 后，可以提出：

```text
请为当前项目建立中文代码地图，按模块说明职责、关键入口和相关文档，
沿用已有导航约定，没有导航时使用 docs/ai-nav/。
```

已有导航时，可以限定增量范围：

```text
请根据本次源码变更同步代码导航，保留现有文档中的手写修改指南。
```

该 Skill 默认按模块索引，按需补充详情；导航信息受变更影响时才维护，不要求逐文件生成镜像。已有逐文件导航保留并按需更新。目录内仅有技能说明，未附带自动运行的 hook 或脚本。

### 按模块开发

读取 `modular-development/SKILL.md` 后，可以提出：

```text
请按 modular-development 流程实现 <具体功能>，
先核对业务归属、已有工具与组件，再完成实现和验证。
```

新项目会先进入[项目起步流程](modular-development/references/project-bootstrap.md)，明确技术栈、模块职责、依赖约定，并完成首个可验证的完整功能。已有项目则从当前结构出发，定位能力归属与复用位置。

纯文案、格式和局部静态样式调整无需启动完整的模块化开发流程。

## 配合使用

两个 Skill 可以分别使用，也可以在同一项开发任务中配合：

1. 需要梳理代码时，使用 `codebase-navigator` 建立或更新导航。
2. 实现功能时，使用 `modular-development` 确认模块归属、复用能力与验证方式。
3. 完成开发后，按实际变化同步相关导航与架构说明。

## 维护说明

- 新增 Skill 时使用独立目录，并在上方清单中补充用途和入口。
- 修改流程时，同步更新受影响的引用文档和示例。
- README 负责提供概览与使用入口，详细规则保留在对应 Skill 中。
